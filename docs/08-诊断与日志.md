# 专题：诊断与日志

> 来源：原《设计文档.md》§15（2026-10-08 按用户裁定拆分）。
> 本节保留诊断层沿革；当前受限恢复契约以《04-恢复事务与校验》为准。用户后续要求普通列表和读档，旧硬门已被有条件预检替代。

## 1. 操作链路（原 §15.1）

- 请求分配单游戏线程操作编号，从等待一直带到捕获、编码、写盘和回读；保存源区分 game-message/system-frame。
- 每阶段更新内部上下文（即使被日志级别过滤也更新），记录前阶段耗时及写内存标志；默认 debug（中文“调试”）保留提交/验证、capture/资源/绘制子阶段、紧凑部队摘要及机器装备；正常相等段CRC和重复readback展开放到trace。回滚/不一致为warn（段号、两侧长度/CRC、首差异和两侧12字节均保留），失败和部分写入为error，正常取消/窗口拒绝为info。只有用户明确要求才切回info；缺失或未知配置值fallback=debug。失败保留stage/side/slot/writing，Guard自记录不降级。
- 2026-10-10 日志减量：本机0.10样本323.88秒、2304行、340657B，Execute/Spell共1080行，旧0.9异常样本5871行中Guard占85.8%。已初始化战斗保留每次动作/施法一条调用前debug摘要（native未返回仍可查），成对逐次前后明细改为trace并留最近96条自有内存上下文。普通命令原始/translated同样入环；保存/改键/空格边缘和法术书/等待/防御控件仍debug直写。每5秒Activity收账调用次数、最大深度、最近动作/结果，换场/退出补账。首次异常、周期异常、非栈溢出fatal、操作失败/验证差异、退出和点击打包日志补录近期上下文；明确记录覆盖数/竞争丢弃，环不是完整历史。写盘失败不标为已报告，可重试；栈溢出不执行额外上下文格式化。debug减量不能削弱上述故障取证。
- 每行紧凑部队最多4槽，格式为`slot:t类型/p位置/n存活/d永久死亡/h损血/s初始数量/m士气/l幸运/e法术数/c克隆/a弹药/f动画.帧`；沿用原部队诊断全部字段，弹药车及四机器装备在Hero记录。captured/before-restore/after-restore保留，回滚单列after-rollback；成功readback重复展开仅trace。
- 2026-10-07 日志审计：最新实机样本约3分钟42,757B/322行（info194、debug125、warn1），其中绘制78+20行、阶段相关110行。将稳定绘制心跳移到 trace 每30秒，debug 仅记录场次/对话框/矩形变化；列表/绘制重复失败首条及每30秒汇总 suppressed，恢复/换场补记计数，不熔断功能。debug 新增原始键盘/原生按钮消息与改写后的 cmd/subtype/itemId，以及动作执行前后 action/turn/side/slot，使用 generation/depth 串联；鼠标移动不落盘。仅获准单元测试验证实际日志过滤和纯分级/限频策略，实机日志量仍需用户新会话验证。
- 保存窗口与时机判定契约见《05-UI与输入》第 5 节（原 §15.1 相应条目已移入该文）。
- ArchiveStore::Save 返回实际提交记录（path 含可能的同秒撞名后缀）。写盘成功后按需读取该条文件，校验文件 CRC、比较各段原始字节并解码；列表索引仅保留 metadata，不缓存所有档案 payload；所有档案永久保留，不执行自动清理。
- 普通列表读档入口执行 List/Load/Decode及场次校验，恢复事务各阶段记录日志。提交后新采集/编码，不 memcmp 容器或结构体，逐段比较长度和首差异偏移。
- 含 STL 容器的 CodecCapture 改为值初始化/赋值，禁止 memset 对象头；相同规则用于测试快照。
- codec v7的部队摘要新增 `shots`（`infoCombat[6]`）、本侧弹药车装备ID；英雄摘要记录存在标记及四机器槽ID/subtype。读档记录 `before-restore` 与 `after-restore`，英雄段增至74字节并参与严格比较。旧日志的 `dead` 是永久死亡数量，不是死亡标志；没有shots/装备字段时不能臆造其数值或宣称直接观测到了免扣弹条件。

## 2. 四层 CrashGuard（原 §15.2）

复制通用 CrashGuard/Core，日期日志初始化后安装 VEH 和 UEF；不论 SoD 门卫是否通过都能记录崩溃。挂钩前检查力场静态表。目标 exe 文件偏移 0x23CF18/0x23CF2C 已读字节：格数 WORD 位于 +0x06（2/3），相对格位于 +0x08（0,-16 / 0,-16,-34），DEF 指针位于 +0x10。

所有本次修改的 HiHook 自有逻辑分为原函数前/后保护段，原函数在 SEH 之外、恰好一次；LoHook 出错返回 EXEC_DEFAULT；系统输入钩子出错透传。首异常完整报告，以后每钩子最多每5秒周期汇总新增/累计、最近留存异常码、故障地址及AV访问地址/操作；换场/退出/反馈补记未报告余量，force不重置周期门控。正常Cycle也可收取异常停止后的余量，但不把静默补账称为游戏恢复安全。Interlocked累计与立即退让的try-lock分开；竞争未留存签名时显式告知，不用旧地址冒充全部异常。日志完整写成功才结账，VEH/UEF分发和fatal全量累计不变，不熔断。DETACH只证明卸载收尾，不单独判正常退出。
